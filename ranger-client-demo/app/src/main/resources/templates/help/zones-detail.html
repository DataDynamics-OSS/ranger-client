영역의 구성

필드뜻
services서비스 이름 → 그 서비스에서 영역에 속한 리소스 목록
tagServices영역에 연결된 태그 서비스
admins영역 정책을 관리하는 주체(USER / GROUP / ROLE)
auditors영역 감사 기록을 볼 수 있는 주체

update와 updatePartial

  • update(이 화면): JSON 전체로 영역을 바꿔 씁니다. JSON에서 지운 리소스는 영역에서도 빠집니다.
  • updatePartial(목록 화면): 바꿀 것만 보냅니다. 여러 사람이 동시에 고칠 때 서로 덮어쓰지 않습니다.
위쪽 "이 영역의 정책" 링크는 정책 화면에서 PolicyFilter.all().zone(…)로 검색합니다. 시드 영역 finance에는 정책이 없으므로 빈 목록이 정상입니다.

이 화면이 쓰는 API

RangerSecurityZone zone = admin.zones().getByName("finance");
// 서비스별 리소스와 그 id
List<Map<String, Object>> res = admin.zones().resources(zone.getId(), "demo_hive");

admin.zones().update(zone.toBuilder().description("new").build());
admin.zones().delete(zone.getId());
