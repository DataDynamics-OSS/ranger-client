태그 기반 정책이란?

리소스 기반 정책은 "sales.customers.email 컬럼"처럼 리소스 이름으로 권한을 정합니다. 민감한 컬럼이 여러 서비스에 흩어져 있으면 정책도 흩어집니다. 태그 기반 정책은 대신 리소스에 태그(예: PII)를 붙이고, "PII 태그가 붙은 것은 analyst가 볼 수 없다"처럼 태그에 정책을 겁니다.

태그 정의 PII (속성 level)
   └─ 태그 PII {level=high}
          │ 매핑
          ▼
   서비스 리소스 (demo_hive) database=sales, table=customers, column=email

태그 서비스 demo_tag ── 정책 "PII → …"
서비스 demo_hive ── tagService = demo_tag   (그래서 위 정책이 demo_hive에도 적용)

네 가지 객체

객체뜻
태그 정의 (tag def)태그의 종류와 속성 목록. 예: PII, 속성 level
태그 (tag)정의의 실제 값 하나. 예: PII {level=high}
서비스 리소스태그를 붙일 리소스. 서비스 이름 + 리소스 요소
매핑 (tag resource map)태그 ↔ 서비스 리소스 연결. guid 둘로 만듭니다.

실제 운영에서는 보통 Apache Atlas 같은 메타데이터 시스템이 태그를 동기화(tagsync)합니다. 이 화면은 SDK로 직접 넣습니다.

이 화면 사용법

  • 위의 서비스 칸은 아래 "서비스 리소스" 표와 매핑 폼의 리소스 목록에 쓰입니다.
  • 매핑: 목록에서 태그와 리소스를 골라 map / unmap 합니다.
  • 태그 정의·태그·서비스 리소스 폼의 updateIfExists를 켜면 같은 것이 있을 때 실패하는 대신 고칩니다.
  • 삭제 폼은 표에 보이는 id를 받습니다.

따라 해 보기

  1. 시드 데이터로 PII {level=high} 태그가 sales.customers.email에 매핑되어 있습니다. 표에서 확인하세요.
  2. 서비스 리소스에서 기본값(sales.orders.card_number)으로 createResource를 누릅니다.
  3. 태그에서 종류 PII, 속성 level=low로 새 태그를 만듭니다(PII #2).
  4. 매핑에서 새 태그와 방금 만든 리소스를 골라 map합니다. 한 번 더 누르면 RangerConflictException입니다.
  5. 이 상태에서 리소스를 deleteResource하면 태그와 연결되어 있어 실패합니다.
  6. unmap하면 매핑과 함께 (마지막 매핑이었던) 새 태그도 사라집니다. 그다음 리소스 id로 deleteResource합니다.
Ranger 2.9는 매핑을 지울 때 그 태그도 함께 지우려 합니다. 그래서 태그에 다른 매핑이 남아 있으면 unmap이 실패하고 (RangerValidationException, 400), 마지막 매핑이면 태그까지 사라집니다. 연습할 때는 PII 대신 새 태그를 만들어 매핑하세요. 시드 태그 PII와 그 매핑은 지우거나 unmap하지 마세요.

이 화면이 쓰는 API

List<RangerTagDef> defs = admin.tags().listDefs();
List<RangerTag> pii = admin.tags().byType("PII");

RangerServiceResource res = admin.tags().createResource(RangerServiceResource.builder()
        .serviceName("demo_hive")
        .resourceElements(Map.of("database", PolicyResource.of("sales"),
                "table", PolicyResource.of("orders"), "column", PolicyResource.of("card_number")))
        .build(), true);                      // updateIfExists

admin.tags().map(pii.get(0).getGuid(), res.getGuid());
admin.tags().unmap(pii.get(0).getGuid(), res.getGuid());
admin.tags().deleteResource(res.getId());
