대시보드

ranger-sdk-spring-boot-starter가 ranger.* 설정으로 만든 클라이언트 빈 세 개의 연결 상태와, Admin 서버가 지원하는 기능입니다. 아래 값은 모두 화면을 열 때 실제로 조회한 것이고, 각 값 뒤의 SDK 호출을 볼 수 있습니다.

연결

서버빈URL (노드 사용 가능 여부)인증확인
확인에 쓴 SDK 호출

기능 감지

SDK는 기능마다 한 번만 확인하거나(ranger.admin.server-version을 설정하면 그 값을 씀), 서버에 없는 API를 부르기 전에 UnsupportedFeatureException을 던집니다.

데모 데이터

시작할 때 SDK로 넣은 데이터입니다: 사용자, 그룹, demo_hive 서비스, Policy as Code로 넣은 정책, 보안 영역, 태그, KMS 키. 모든 단계가 upsert이므로 다시 실행해도 안전합니다.
