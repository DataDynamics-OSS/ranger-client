PDP 권한 확인

Ranger 2.9의 정책 결정 지점(PDP, /authz/v1)에 RangerPdpClient로 권한 결정을 묻습니다. 클라이언트는 신뢰 헤더 X-Forwarded-User로 demo-app으로 인증하고, demo-app은 위임 사용자이므로 어떤 사용자를 대신해서든 물을 수 있습니다. 기본 서비스: demo_hive (hive). PDP가 Ranger 사용자 저장소에서 그룹과 역할을 찾으므로 사용자 이름만 있으면 됩니다.

클라이언트 쪽 결정 캐시

스타터 빈에는 캐시가 없습니다(기본값: 정책 변경이 늦게 보이지 않도록). 두 번째 클라이언트는 RangerPdpClient.builder()…cache(Duration.ofSeconds(30), 1000)로 만들어 같은 요청에 로컬에서 답합니다. 두 번째 호출에는 HTTP 요청이 없습니다. 캐시 키는 requestId와 accessTime을 뺀 요청입니다.
