JSON 모양

{
  "name": "analysts",
  "users":  [ { "name": "alice",   "isAdmin": false } ],
  "groups": [ { "name": "analyst", "isAdmin": false } ],
  "roles":  []
}

구성원 목록은 통째로 바뀝니다. 한 명을 빼려면 그 항목을 지우고 저장하세요.

update와 apply

  • update: id로 찾아 고칩니다. 없으면 RangerNotFoundException.
  • apply: 이름으로 찾아 있으면 고치고 없으면 만듭니다. 이름을 바꿔 저장하면 새 역할이 생깁니다.
정책이 쓰고 있는 역할은 Ranger가 삭제를 거부할 수 있습니다. 그때 오류 상자의 예외 타입과 서버 메시지를 확인하세요.

이 화면이 쓰는 API

RangerRole role = admin.roles().getByName("analysts");
RangerRole changed = role.toBuilder().description("changed").build();
admin.roles().update(changed);
admin.roles().delete(role.getId());
