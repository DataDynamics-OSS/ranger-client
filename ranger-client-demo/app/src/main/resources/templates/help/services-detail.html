주요 필드

필드뜻
type서비스 정의 이름(hive, hdfs …). 만든 뒤에는 바꿀 수 없습니다.
configsRanger가 리소스를 조회(lookup)할 때 쓰는 접속 정보
tagService함께 평가할 태그 서비스
policyVersion정책이 바뀔 때마다 올라갑니다. 플러그인은 이 값으로 새 정책이 있는지 압니다.

가려진 비밀번호

Ranger는 configs의 비밀번호를 *****로 돌려줍니다. 이 값을 그대로 다시 보내면 Ranger는 저장된 비밀번호를 유지하므로, JSON의 다른 부분만 고쳐 저장해도 비밀번호가 바뀌지 않습니다.

testConnection

Ranger Admin이 configs로 실제 시스템에 접속해 리소스 조회가 되는지 봅니다. 결과는 예외가 아니라 맵으로 오므로, 접속에 실패해도 호출은 "성공"이고 결과 안에 실패 내용이 들어 있습니다.

이 화면이 쓰는 API

RangerService svc = admin.services().getByName("demo_hive");
admin.services().update(svc.toBuilder().description("changed").build());
Map<String, Object> result = admin.services().testConnection(svc);
admin.services().deleteByName("sdk_demo_hdfs");
