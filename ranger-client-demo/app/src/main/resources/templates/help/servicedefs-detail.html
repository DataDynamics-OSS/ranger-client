리소스 계층

리소스는 level과 부모(parent)로 계층을 이룹니다. Hive라면:

database (level 10)
 ├─ table   (20) ─ column (30)
 └─ udf     (20)
url, global, hiveservice  (독립)

정책의 리소스는 이 계층의 한 경로를 따라야 합니다. 예: database=sales; table=orders; column=*.

  • 필수(mandatory): 그 경로를 쓰면 반드시 값을 줘야 하는 리소스
  • recursive: 하위까지 포함하는 옵션(HDFS 경로 등)을 지원하는지
  • excludes: "이 값만 빼고"를 지원하는지

권한과 포함 관계

포함하는 권한(impliedGrants)이 있는 권한은 그것만 줘도 나열된 권한을 함께 받습니다. 예: Hive의 all은 select, update, create … 를 모두 포함합니다.

마스킹 종류

마스킹 정책에서 고를 수 있는 값입니다. 변환식은 Hive 플러그인이 쿼리를 바꿀 때 씁니다. 예: MASK_HASH → mask_hash({col}). 시드 정책은 MASK_HASH를 씁니다.

이 화면이 쓰는 API

RangerServiceDef def = admin.serviceDefs().getByName("hive");
List<Map<String, Object>> resources = def.getResources();     // 중첩 부분은 맵
List<Map<String, Object>> accessTypes = def.getAccessTypes();

중첩된 부분을 맵으로 두는 이유는 Ranger 버전마다 필드가 자주 바뀌기 때문입니다. 원본 JSON은 아래 "원본 JSON"에서 볼 수 있습니다.
