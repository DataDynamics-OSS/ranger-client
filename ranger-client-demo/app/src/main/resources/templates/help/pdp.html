PDP란?

Ranger Admin은 정책을 저장·관리하고, 실제 판단은 각 서비스(Hive, HDFS …)에 붙은 플러그인이 합니다. Ranger 2.9부터는 판단만 하는 별도 서버 PDP(Policy Decision Point)가 있어서, 플러그인을 넣을 수 없는 애플리케이션도 REST로 권한을 물을 수 있습니다.

앱 ──authorize──▶ ranger-pdp ──(5초마다 정책 받기)──▶ ranger-admin
     ◀─ ALLOW / DENY ─┘   사용자·그룹·역할도 Admin에서 받아 둠

요청과 결정

요청 항목예
사용자 (+그룹, 역할)alice. 그룹·역할은 비우면 PDP가 찾아 줍니다.
리소스database=sales, table=orders
권한(permission)select, update, alter …

결과의 결정은 ALLOW, DENY, NOT_DETERMINED 중 하나이고, 권한마다 어느 정책이 결정했는지(정책 열), 마스킹·행 필터가 있으면 그 내용도 옵니다. 맞는 정책이 없으면 정책 id가 -1이고 기본값으로 거부됩니다.

X-Forwarded-User와 위임 사용자

이 앱은 PDP에 사용자 비밀번호를 보내지 않습니다. 대신 신뢰 헤더 X-Forwarded-User: demo-app로 자신을 밝히고, 요청 본문에 판단받을 사용자(alice 등)를 넣습니다. PDP는 demo-app을 위임 사용자 (delegation user)로 등록해 두었으므로(ranger-pdp-site.xml) 다른 사용자를 대신한 질문을 받아 줍니다. 위임 사용자가 아니면 자기 자신에 대해서만 물을 수 있습니다.

신뢰 헤더 인증은 PDP 앞단(프록시, 내부망)에서 헤더 위조를 막을 때만 안전합니다. 운영에서는 Kerberos나 JWT를 쓰세요.

이 화면 사용법

  • 시드 시나리오 버튼은 정해 둔 질문을 바로 보냅니다. 버튼 아래 줄이 기대하는 답입니다.
  • 여러 권한 한 번에: 한 줄에 리소스 | 권한 하나씩. 요청은 한 번만 갑니다.
  • 리소스에 접근할 수 있는 주체: 반대 방향 질문, "누가 이 테이블을 볼 수 있나?"
  • 캐시: 같은 질문을 캐시 없는 빈과 캐시 있는 클라이언트로 보내 HTTP 요청 수를 비교합니다.

따라 해 보기

  1. mallory · select · database=sales, table=orders를 누릅니다. mallory는 analyst 그룹이지만 sales_read 정책의 거부 항목 때문에 DENY입니다.
  2. 정책 화면에서 sales_read의 DENY 항목에서 mallory를 removePrincipals로 뺍니다.
  3. 5초쯤 뒤 같은 버튼을 다시 누르면 ALLOW가 됩니다. (되돌리려면 addItems로 DENY에 mallory를 다시 넣으세요.)
  4. alice · select · …customers, column=email은 허용되지만 MASK_HASH 마스킹이 붙습니다.

이 화면이 쓰는 API

RangerPdpClient pdp = RangerPdpClient.builder()
        .urls("http://ranger-pdp:6500")
        .auth(TrustedHeaderAuth.of("X-Forwarded-User", "demo-app"))
        .service("demo_hive", "hive")
        .build();

AuthzResult r = pdp.authorize("alice", ResourceInfo.of("database", "sales", "table", "orders"), "select");
if (r.isAllowed()) { /* … */ }

boolean ok = pdp.isAllowed("mallory", ResourceInfo.of("database", "sales", "table", "orders"), "select");
ResourcePermissions who = pdp.permissions(ResourceInfo.of("database", "sales", "table", "orders"));

스프링 부트 스타터를 쓰면 위 빌더 대신 ranger.pdp.* 설정으로 RangerPdpClient 빈이 만들어집니다(이 앱이 그렇습니다).
