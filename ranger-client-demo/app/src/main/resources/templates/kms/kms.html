KMS

RangerKmsClient로 키를 관리합니다(Ranger KMS가 제공하는 Hadoop KMS REST API). 클라이언트는 Hadoop simple 인증으로 keyadmin(?user.name=keyadmin)이 되고, dev_kms 정책이 keyadmin에게 모든 키 작업을 허용합니다. 다른 사용자의 키 작업은 그 정책에 막힙니다(RangerAccessDeniedException).

암호화된 데이터 키 (EEK)

HDFS 암호화 영역이 KMS를 쓰는 방식입니다. KMS는 영역 키로 암호화한 데이터 키(EEK)를 내주고, decrypteek 권한이 있는 클라이언트는 평문 데이터 키를 돌려받습니다. 키를 롤오버한 뒤 reencryptEek는 데이터 키를 드러내지 않고 EEK를 새 키 버전으로 옮깁니다.
