보안 영역

보안 영역(security zone)은 서비스의 리소스 일부를 떼어 내어 따로 정책과 관리자를 두게 합니다. SDK는 v2 영역 API (Feature.ZONES_V2로 감지)를 쓰며, 영역 전체를 다시 보내지 않고 일부만 바꾸는 부분 수정도 지원합니다.
