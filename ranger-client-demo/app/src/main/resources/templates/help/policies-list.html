정책이란?

Ranger 정책(policy)은 하나의 서비스(예: demo_hive) 안에서 "어떤 리소스에 대해 어떤 주체(사용자·그룹·역할)에게 어떤 권한을 주거나 막는지"를 적은 규칙입니다.

정책 sales_read (서비스 demo_hive)
 ├─ 리소스   database=sales, table=*, column=*
 ├─ 허용     role  analysts → select
 │           group engineer → select, update, alter
 └─ 거부     user  mallory  → select

정책 이름은 서비스 안에서 유일합니다. 그래서 SDK는 (서비스, 이름)을 정책의 자연 키로 씁니다.

정책 종류

종류policyType무엇을 하나
접근0허용·거부 항목으로 접근을 정합니다. 가장 흔합니다.
마스킹1컬럼 값을 가려 보여 줍니다(MASK_HASH, MASK_SHOW_LAST_4 …).
행 필터2조건에 맞는 행만 보여 줍니다(예: region = 'APAC').

항목 평가 순서

한 정책 안의 항목 목록은 네 가지이고, Ranger는 이 순서로 평가합니다.

  1. DENY 중 DENY_EXCEPTIONS에 걸리지 않은 것 → 거부
  2. ALLOW 중 ALLOW_EXCEPTIONS에 걸리지 않은 것 → 허용
  3. 아무것도 맞지 않으면 → 결정 안 됨(다른 정책이나 기본값으로)
시드 데이터에서 alice는 역할 analysts의 멤버라 sales_read의 허용 항목으로 허용되고, mallory는 거부 항목 때문에 거부됩니다. PDP 권한 확인 화면에서 직접 확인해 보세요.

이 화면 사용법

  • 검색: 빈 칸은 조건에서 빠집니다. 필터는 모두 서버에서 적용되고, 페이지 크기로 나눠 받습니다.
  • 정책 만들기: 리소스 하나 + 허용 항목 하나 + 거부 항목 하나를 빌더로 만듭니다. 쉼표로 여러 값을 넣습니다.
  • 항목 바꾸기: 정책 전체 JSON 없이 주체만 더하거나 뺍니다.
  • forResource / forUser: "이 테이블에 걸린 정책은?", "mallory가 들어간 정책은?"에 답합니다.
  • Export / import: 서비스 전체 정책을 JSON 하나로 옮깁니다.
import의 override를 켜면 Ranger가 대상 서비스의 정책을 모두 지운 뒤 들여옵니다. override 없이 이름이나 리소스가 겹치는 정책을 들여오면 RangerConflictException이 납니다.

apply / create / serverApply

메서드같은 이름이 있으면
apply그 정책을 고칩니다(SDK의 이름 기준 upsert). 다시 실행해도 안전합니다.
createRangerConflictException(409)
serverApplyRanger의 /policy/apply: 같은 리소스의 정책에 항목을 합칩니다.

이 화면이 쓰는 API

Page<RangerPolicy> page = admin.policies().search(
        PolicyFilter.service("demo_hive").user("mallory").start(0).limit(10));

RangerPolicy policy = RangerPolicy.builder()
        .service("demo_hive").name("sdk_demo_marketing")
        .resource("database", "marketing").resource("table", "*")
        .allow(PolicyItem.groups("analyst").accesses("select"))
        .build();
admin.policies().apply(policy);           // 이름 기준 upsert

admin.policies().addItems("demo_hive", "sales_read", ItemKind.ALLOW,
        List.of(PolicyItem.users("bob").accesses("select").build()));
List<RangerPolicy> hits = admin.policies().forUser("mallory", "demo_hive").toList();

검색은 GET /service/public/v2/api/policy?serviceName=…&startIndex=…&pageSize=… 한 번입니다. 화면 아래 요청 기록에서 쿼리 문자열과 응답 본문을 펼쳐 볼 수 있습니다.
